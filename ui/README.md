# UI scaffold

Minimal Vite + React + TypeScript frontend scaffold for the Tauri migration.

## Run

```bash
npm install
npm run dev
```

By default this starts on Vite's default port. For Tauri integration, `src-tauri/tauri.conf.json` starts it on port `1420`.

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```
